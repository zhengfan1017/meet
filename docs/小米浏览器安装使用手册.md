# Trae宝 · 小米浏览器从零安装使用手册

这份手册面向「我还没下载过 Trae宝」的读者，从拿到网址开始，一步一步做到在手机桌面上跟 Trae宝 聊天。

全程大约 5 分钟，其中大部分时间是在填一个 API Key。

---

## 0. 先搞懂一件事：Trae宝不用下载安装包

Trae宝是一个**网页应用（PWA）**，不是手机 App。

- 没有 `.apk`、没有应用商店、不占手机存储
- 你只需要在浏览器里打开一个网址，然后「添加到桌面」
- 添加之后，桌面上会出现一个图标，点开就像独立 App 一样，全屏、没有地址栏

数据（聊天记录、记忆、API Key）全部存在**你自己手机本地**，不上传任何服务器。

---

## 1. 拿到网址

**Trae宝 线上地址：**

```
https://traebao-app-2.surge.sh/
```

把它复制下来，或者直接记在手机备忘录里。

> 如果你想自己部署一份，README 的「部署到线上」一节有 GitHub Pages / Cloudflare Pages 两种方式，部署完同样是拿到一个网址。

---

## 2. 在小米浏览器里打开

1. 打开手机上的**小米浏览器**
2. 地址栏粘贴 `https://traebao-app-2.surge.sh/`
3. 回车 / 点「前往」

首次打开时，浏览器可能问你要不要「允许通知」或「添加到桌面」，**先点「取消」或忽略**，我们手动来。

页面应该显示：顶栏左边一个「设置」按钮，中间是 Trae宝 的立绘，下面是聊天区和输入框。

> ⚠️ **如果打不开**：
> - 显示「无法访问此网站」→ 换个网络（Wi-Fi / 流量）再试
> - 一直转圈 → 检查手机是否开了「代理」或 VPN，有的话临时关掉
> - 打开了但是白屏 → 往下看第 6 节的「白屏」

---

## 3. 添加到桌面（这一步是「安装」）

小米浏览器**不会**触发浏览器的自动安装提示，所以必须手动来：

1. 点屏幕底部或顶部的 **≡ 菜单按钮**（有些版本是右下角三个点）
2. 往下翻，找到 **「添加到桌面」**
   - 如果没有这一项，找 **「新建快捷方式」** 或 **「添加书签到桌面」**，效果一样
3. 名字改成 **Trae宝**（默认可能显示网址，别管它也行）
4. 点「确定」/「添加」

回到手机桌面，你应该能看到一个 **Trae宝 的图标**（米色底、绿色方块机器人）。点它，就会全屏打开。

---

## 4. 第一次配置：填 API Key

Trae宝 本身不绑任何账号，第一次用要先告诉它「用哪个模型、Key 是什么」。

### 4.1 拿到火山方舟的 Key

Trae宝 默认对接 **火山方舟（豆包大模型）**：

1. 打开火山方舟控制台：https://console.volcengine.com/ark
2. 注册 / 登录（手机号或邮箱都行）
3. 开通「推理接入点」服务（首次会有免费额度，按提示领）
4. 创建一个**推理接入点**，选模型
5. 复制两样东西：
   - **API Key**（在「API Key 管理」里创建，形如 `xxxxxxxx-xxxx-xxxx`）
   - **模型 ID**（就是创建接入点时填的模型名，或者接入点详情里的 Endpoint ID）

> ⚠️ **模型 ID 一定要带日期后缀**。控制台里显示的名字（`Doubao-Seed-2-1-pro`）是给人看的，
> 填进 Trae宝 会报 `InvalidEndpointOrModel.NotFound`。真正能用的是带日期的那个：
> `doubao-seed-2-1-pro-260915`、`doubao-seed-2-1-pro-260628`、
> `doubao-seed-2-1-turbo-260628`、`doubao-seed-2-1-lite-260915`、
> `doubao-seed-2-0-mini-260428`、`doubao-seed-2-0-lite-260428`。
>
> 记不住？**不用记**——Trae宝 里有「自动找模型」按钮，见下一节。

### 4.2 在 Trae宝 里填

1. 点开桌面上的 Trae宝 图标
2. 点顶栏的 **「设置」**
3. 按下面填：

| 字段 | 填什么 |
| --- | --- |
| 接入方式 | **方舟直连** |
| 接口地址 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions`（一般不用改） |
| API Key | 粘贴你复制的 Key |
| 模型名 | 粘贴你的模型 ID（**要带日期后缀**，见上面） |

4. 顺手做两件事验证一下：

   - 点 **「测试连接」** → 出现「连接正常，模型名可用」说明三项都对。
     如果出现 `失败（404）InvalidEndpointOrModel.NotFound`，就是模型名少了日期后缀。
   - 懒得找模型名，直接点 **「自动找模型」** → Trae宝 会挨个试一遍当前可用的模型 ID，
     找到能用的那个自动填进去（再点一次「保存」即可）。

5. 点 **「保存」**
6. 关掉设置面板

> **API Key 安全吗？**
> Key 只存在你手机的 IndexedDB 里，浏览器直接请求方舟，不经过 Trae宝 的任何服务器。
> 但共用设备的话，Key 会出现在请求头里，建议用下面第 6 节的 Worker 代理方案。

---

## 5. 开始聊天

底部输入框打字 → 点「发送」。

你会看到：

- Trae宝 的立绘切换表情（思考 / 打气 / 开心…）
- 回复**逐字出现**，像真人打字
- 聊得多了，它会开始**记住你的事**（比如「你最近常加班到很晚」），下次自动带上

想看它记住了什么：点 **「设置」→「它记住的事」**，可以置顶、删除，或者一键「清除所有数据」。

---

## 6. 常见问题

### 发了消息，Trae宝完全没反应

先看屏幕上那条红色横幅写的是什么，它已经把真实原因写出来了：

| 横幅 | 真实原因 | 怎么办 |
| --- | --- | --- |
| `模型名或接口地址不对（InvalidEndpointOrModel.NotFound）` | 模型名少了日期后缀 | 设置里点 **「自动找模型」**，然后「保存」 |
| `API Key 不对` | Key 填错或失效 | 检查 Key；确认方舟控制台里这个 Key 还有效 |
| `额度用完了` | 余额/配额用完 | 去方舟控制台充值，或换个便宜模型 |
| `连不上模型` | 网络或跨域被拦 | 换网络试；还是不行就走 Worker 代理（下面有） |
| `模型服务出错了` | 方舟服务端故障 | 等几分钟再发一次 |

> **模型名填错了也不用手动改**：Trae宝 收到 404 会自己找一个能用的模型名换上去，
> 顶部会提示「模型名不对，已自动切换到 xxx」，这次对话照常继续。

### 页面上的按钮点了没反应 / 界面看着是旧的

这是浏览器缓存把新旧代码混在一起导致的（页面是新版本，脚本还是旧版本，
于是按钮在但事件没绑上）。

**最快的解法**：设置面板最下面点 **「页面有问题？清缓存重载」**，
它会清掉所有缓存、注销 Service Worker、重新加载页面。

**还不行的话**：浏览器菜单 → 清除缓存 / 用无痕模式打开一次。

Trae宝 本身也做了防混搭：代码类资源统一「网络优先」，每次打开拿到的都是同一套。

### 白屏 / 打开是一堆乱码

小米浏览器的旧版本（MIUI 12 时代的机型）可能不支持某些新语法。Trae宝 已经做了降级处理，如果还是白屏：

1. 浏览器菜单 → **清除缓存 / 无痕模式** 打开一次试试
2. 或者把浏览器更新到最新版本
3. 再不行换 Chrome 打开

### 提示「连不上模型」

方舟接口偶尔会拦跨域直连。**换 Worker 代理**（README「模型配置 → 方式二」有完整步骤，一分钟能部署好）。部署完在设置里把「接入方式」改成「Worker 代理」，填上 Worker 地址和访问令牌。

### 装到桌面后打开还是跳浏览器

部分 MIUI 版本对 PWA 的独立窗口支持不完整，会带顶部地址栏，但**功能完全正常**，不影响使用。

### 微信里打开的页面不能添加到桌面

微信内置浏览器是 WebView，装不了 PWA。必须用系统浏览器（小米浏览器 / Chrome）打开。

### 关掉再打开，聊天记录没了？

不应该丢。记录存在本地 IndexedDB 里。如果确实没了，在设置里点「清除所有数据」重新开始 —— 那说明本地数据被系统清理了（小米系统的省电策略有时会清缓存），可以在系统设置里给这个网页加个「不清理」。

### 想换手机 / 换模型

记忆和聊天记录不跨设备。想带走的话，在「设置 → 它记住的事」里手动抄下来；或者之后再加导出功能。

### 想让 Trae宝 更有用

- 设置里的「模型名」可以换更聪明的模型，代价是更慢更贵
- 「模型配置 → 方式一」里提到的接口地址可以改成任何 OpenAI 兼容的接口

---

## 一句话总结

**打开网址 → ≡ 菜单「添加到桌面」 → 设置里填 Key → 开始聊。**
